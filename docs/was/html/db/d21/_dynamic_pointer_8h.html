Detailed Description

Type-safe dynamic integer pointer with metadata tracking.

Provides runtime access to integer variables with automatic size/signedness detection. Supports both internal (stack) and external (pointer) storage modes.

Warning
Watch for integer overflow since exact type is determined at runtime.
