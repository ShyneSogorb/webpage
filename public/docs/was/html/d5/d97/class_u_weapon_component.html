Detailed Description

UWeaponComponent is a component that handles weapon functionality such as triggering, reloading, and managing ammo.

◆ SetAmmoSourceFromMap()

void UWeaponComponent::SetAmmoSourceFromMap ( const TMap< int32, int32 > & Map,
const int32 & InKey,
bool ReturnRemainingAmmo = true )

Sets the value of a map as the source of the ammo. This node exists since there's no find by ref in Map containers unlike in arrays that offer get by ref. IMPORTANT. Even tho the Key of the map can be of any type, the value must be a value with reinterpretation as int64 (eg, int32, enum, uint8, int16, etc.) with any other type expect undefined behaviour and crashes

Parameters
MapThe map from where the ammo will be collected
InKeyKey value that must be found in the map in order to use its value as source ammo
ReturnRemainingAmmoIndicates if it should return to the old source the ammo that remains
